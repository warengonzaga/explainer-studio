# Set up Explainer Studio

Resolve the plugin root from this file (`../..`). Pass `--json` and read the stdout object (`ok`, `command`, `data`, `next_steps`, `error`). A failure exits non-zero. Run `python <plugin-root>/scripts/explainer.py bootstrap --json` to install Studio's Python dependencies into its managed user environment, then run `doctor --json`. Explain missing tools in plain language. Python 3.11+, Node.js 22+ with npm, FFmpeg, ffprobe, and Chrome or Edge are required; `faster-whisper` is optional until automatic transcription is needed. Rhubarb is also optional. On x86_64 Linux or macOS, `bootstrap --rhubarb --json` installs Rhubarb Lip Sync 1.14.0 and wires `RHUBARB_PATH` for later Studio commands. Do not install it unless the user wants phonetic mouth cues. The launcher uses the managed Python environment for later commands. Do not change system Python or put provider credentials in command arguments, chat output, or `profile.json`.

Explainer Studio uses AIVEE as a shared global CLI. First setup reuses a compatible global npm installation; if AIVEE is missing, install the latest release with `npm install --global aivee@latest`, then call AIVEE to create the default workspace. If an installed AIVEE is incompatible, explain the issue and ask the user to update it with that command; do not silently replace a shared global install. Do not ask users to clone the Engine repository or provide an Engine path. If Node.js, npm, or installation is unavailable, explain the specific prerequisite and stop setup before saving a profile.

Briefly recommend a model for creative planning and animation authoring: Astra for best results in Codex, with Sol as the minimum recommendation; Opus for best results in Claude Code, with Sonnet as the minimum recommendation. The user selects the model in their chat environment. Continue setup with the active model; these are project recommendations, not an enforced runtime requirement. Apply the [motion quality guide](../create-explainer/references/motion-quality.md) when creating the first film.

Ask the user one short grouped set of questions, offering these defaults so setup can be completed with minimal input:

1. Brand defaults to **Explainer Studio**; narration language defaults to English. The AIVEE home defaults to `~/AIVEE`; ask where to place that entire folder only when the user wants a different location. Logo and colors are optional.
2. Ask which narration source should be the default: **ask every time**, **a recording file I provide**, **ElevenLabs**, **Higgsfield**, or **Suno**. Default to **ask every time** unless the user chooses one. Provider access is handled by connected Codex or Claude Code capabilities, not Studio API keys. If a wanted provider is unavailable, point to its official connection guide; do not block setup or silently substitute a provider. These services may consume paid credits. Local TTS is not supported yet. Never require a voice clone.
3. Avatar defaults to the bundled original **Emo** robot pack at `<plugin-root>/library/avatars/emo`. The **Waren (sample)** at `<plugin-root>/library/avatars/waren` and user-owned sprite packs can be selected; preview the contact sheet in chat and get approval before saving a custom pack. See [avatar pack guide](../avatar/references/pack.md).
4. Optional Rhubarb Lip Sync. When configured, Studio uses phonetic cues mapped to its five mouth states, with closed-lip shapes on the closed mouth. Without it, Studio falls back to audio-level mouth timing at the project frame rate. Offer `bootstrap --rhubarb` on x86_64 Linux or macOS, or ask for an existing executable and save it with `--rhubarb-path`.

Save only non-secret user choices through `python <plugin-root>/scripts/explainer.py setup --json [--home <AIVEE-home>] [--brand ...] [--language ...] [--voice-provider-default ask|recording|elevenlabs|higgsfield|suno] [--avatar ...]`; add `--rhubarb-path`, `--avatar-pack`, `--logo`, colors, and `--cta` when chosen. Setup ensures AIVEE is installed, asks AIVEE to initialize its workspace, and saves the returned paths. The default AIVEE home is `~/AIVEE`; projects and the Explainer Library are managed there by AIVEE. Defaults are **Explainer Studio**, English, ask before each voice generation, Emo robot avatar, and the default palette. If a profile exists, show the current non-secret choices with `profile --json`, ask only what should change, and use `--force` for the intentional update. The Studio profile lives at `EXPLAINER_STUDIO_HOME/profile.json`, or `~/.explainer-studio/profile.json` by default. Keep every response and setup result in the chat.

Provider connection references: [ElevenLabs](../elevenlabs-voiceover/SKILL.md), [Higgsfield](../higgsfield-voiceover/SKILL.md), and [Suno](../suno-voiceover/SKILL.md). During setup, explain that provider availability depends on the active host and each service may charge credits. Do not connect accounts or generate audio during setup.

Once setup succeeds, offer to make the first film from a topic. Do not create one until the user supplies a topic.
