# Hook or title card

Use this for the opening line of a scene. It reveals a short hook, a title, and one supporting line inside the open area clear of the avatar and captions.

Text fields: `kicker`, `title`, `support`.

```text
explainer add-template <project> hook-title --scene <number> --set title="..." --set support="..."
```

See [scene starters](../README.md) for theme colors, timing, and formats.
