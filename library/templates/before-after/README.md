# Before and after

Use this when the narration contrasts an earlier state with a later one. The later panel uses the project accent.

Text fields: `before-label`, `before`, `after-label`, `after`.

```text
explainer add-template <project> before-after --scene <number> --set before-label="..." --set before="..." --set after-label="..." --set after="..."
```

See [scene starters](../README.md) for theme colors, timing, and formats.
