# Numbered steps

Use this when the narration lists three actions. Each row reveals in order, with a number and a short label.

Text fields: `step-1`, `step-2`, `step-3`.

```text
explainer add-template <project> numbered-steps --scene <number> --set step-1="..." --set step-2="..." --set step-3="..."
```

See [scene starters](../README.md) for theme colors, timing, and formats.
