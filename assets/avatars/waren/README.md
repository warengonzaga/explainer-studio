# Waren avatar pack

Waren is a bundled sample avatar pack for Explainer Studio. It follows the v1 avatar pack format, with full-body pose sheets and separate eye and mouth sprite sheets.

## Contents

- `poses/talking.png`: idle, present, like, thinking, idea, and celebrate.
- `poses/pointing.png`: seven directional pointing poses, including viewer-facing.
- `poses/emotion.png`: smile, grin, laugh, sad, worried, surprised, and angry.
- `eyes/talking.png` and `eyes/emotion.png`: gaze, blink, and matching expressions.
- `mouth/talking.png` and `mouth/emotion.png`: lip-sync and matching expression shapes.

## Use

Load this folder as an avatar pack in Explainer Studio. The manifest contains frame bounds and face placement. The preview shows the pack through the Studio compositor.
