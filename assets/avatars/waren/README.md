# Waren avatar

An original sample presenter based on Waren Gonzaga's supplied avatar images. The four poses and five mouth states were generated as transparent sprite sheets, then cropped into individual PNGs for Explainer Studio.

Use this pack with `avatar-preview-pack` or choose **Waren (sample)** during setup. The transparent source sheets are kept in `source/`. The character uses neutral, even lighting and audio-reactive mouth states.

The `point` pose keeps Waren's head front-facing while shifting both pupils toward his pointing hand. Mouth patches are fitted to the face in each pose: idle uses `[0.5, 0.28]`, point uses `[0.42, 0.31]`, and present/celebrate use `[0.5, 0.31]`. Point, present, and celebrate mouth patches are scaled to 85%. Each pose has a matching closed-eye frame for automatic blinks. The contact sheet is rendered through the same avatar compositor used in explainer videos.
