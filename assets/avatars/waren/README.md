# Waren avatar

An original smooth chibi sample presenter matching Waren Gonzaga's social avatar. The four poses, five mouth states, and closed-eye blinks share one scale, head height, and feet baseline. Transparent source sheets are kept in `source/`.

Use this pack with `avatar-preview-pack` or choose **Waren (sample)** during setup. Each mouth patch is 110×70 with the mouth centered and feathered skin edges, so it covers the smile drawn on the pose. The contact sheet is rendered through the same avatar compositor used in explainer videos.

Mouth anchors are the patch center as a fraction of the full 840×1240 sprite. Every pose uses mouth width `0.130952` and scale `1`:

- idle: `0.464286`, `0.354839`
- present: `0.465476`, `0.355645`
- point: `0.463095`, `0.354839`
- celebrate: `0.466667`, `0.355645`

The `point` pose keeps the head front-facing while the pupils look toward the pointing hand. Each pose has a matching closed-eye frame at the same size and framing, so blinks stay put.
